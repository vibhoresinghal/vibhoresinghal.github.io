How it works.

No need to write a cleanup brief from scratch. The skill gives Codex a consistent process, with your judgment where it matters.

01

Share the file

Paste one Figma link or a batch of links. Codex inspects the pages, screens, sections, and connections before making changes.

↗
02

Clarify what’s current

Identify what’s live, approved but not implemented, and still experimental. Unknowns stay unknown—“final” in a name isn’t proof.

◎
03

Let the cleanup happen

Related pages become named sections. Screens line up. Loose studies find a home. Clear names and dividers make the sidebar scannable.

▤
04

Review the handover

Get links to the organized work, a summary of changes, and any unresolved questions. Designs and prototype dependencies are checked.

Questions, answered.

      
Will it redesign my screens?
No. The skill organizes existing work: names, pages, sections, and placement. It is instructed to preserve screen internals, original artwork, fonts, and component instances.

      
What happens to links and prototypes?
The workflow moves original nodes and checks prototype starting points and transition dependencies. Removing a merged source page changes its page-level link. Tell Codex upfront if a page URL must remain intact. A structural check is not the same as playing through every interaction.

      
Can I clean up several files?
Yes. Add one link per line to the prompt builder. Codex works file by file, confirms design status where needed, and keeps progress checkpoints. For a large library, start with one representative file, then work through batches.

      
Does it delete old designs?
The skill retains historical designs and distinct alternatives. It removes merged source pages only after their contents are accounted for and the pages are verified empty. Ambiguous duplicates are not automatically deleted.

      
Is this ready for a team rollout?
The skill package passed structural validation and reflects an actual cleanup workflow. It has not yet been independently trialed on another team’s file. Pilot it on a representative file before a broad rollout.
